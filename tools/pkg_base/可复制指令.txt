先整理每镜时码、事件、角色与专属道具、相机路径与目标点、走位和前后状态，再写成 scene.json（用统一模板，不改 app.js 和界面文件）。
页面支持暂停、拖时间轴、切换镜头、调机位、保存配置，并能按画幅逐帧导出流畅的 MP4（16:9 为 1920×1080，21:9 为 2520×1080，9:16 为 1080×1920）。按反馈逐镜修改，保留版本。

【开工确认｜新建工程前会先问这 4 题，避免返工】
开工前技能会读完分镜，再一次性问你 4 个问题（已经在请求里写清楚的就不问）：
1. 人物白膜：精细白膜（四肢、眼带、显示道具）/ 简化胶囊（球头 + 胶囊身体，无四肢、不显示道具，生成时表演更自由）
2. 预演画面亮度：明亮可读，夜景 / 低调光写进提示词（推荐）/ 按分镜影调做暗
3. 分镜机位和空间冲突时：保持空间真实，机位就近调整并标注（推荐）/ 严格按分镜机位，必要时改场景尺寸
4. 这次做到哪一步：只做预演 / 预演 + 导出参考视频 / 预演 + 参考视频 + 生成交接
想跳过提问，可以在第一句话里一次写清，例如：简化胶囊白膜；画面明亮可读；机位装不下时保持空间真实；这次做到预演 + 导出参考视频。
回答会记进工程的 revision-log.md「开工确认」，之后修改都按它来。

【人物白膜｜两种外形，动作完全一样】
精细白膜：球头 + 眼带、可弯曲方块躯干、胶囊四肢，显示道具。适合看清手部接触、四肢动作，或拿去后期微调动作模型。
简化胶囊：球头紧贴与头同直径的胶囊身体，无四肢、无五官、不显示道具，底端离地约 16 厘米悬浮；走、跑、扑、倒地时是一根直的胶囊（整体随重心前倾、倾倒），只有下蹲、坐下才弯曲。
  拿参考视频去生成时用它：视频模型不会照抄白膜的僵硬关节，表演发挥空间更大；生成提示词会自动说明「人物和道具按提示词与参考图重新生成」。
网页顶栏画幅旁的「精细白膜 / 简化胶囊」下拉可随时一键切换（Ctrl+Z 撤销），只换外形，不改动作、接触和道具挂点。

【随包示范案例】
影棚开拍前的忙碌日常，30 秒斯坦尼康一镜到底、14 个角色：场务端咖啡推门进棚 → 递咖啡给推灯的灯光师 → 随灯面升起上摇 → 半环绕补妆的女演员 → 在导演和摄影指导身前后退引导 → 穿过两台监视器 → 从挑杆下钻进客厅布景 → 走上金属楼梯 → 灯光走道上俯拍，布景灯全亮。
新建工程会从这个案例复制，再按你的分镜整份改写；示例预览.png 是它的四格截图，references/complete-example.md 是它的两段交接提示词。

【动作方式】
方式 1 · 关键帧直接做：只用姿态关键帧 + 贴合 + 步态 + 呼吸微动，不需要动作文件，最省 token。不写就是这种。
方式 2 · 混合（关键帧 + 动捕）：走位、机位、接触用关键帧，摔倒、打斗、舞蹈等全身动作用 FBX 动捕片段。
  示例：使用 zpboom-3d-previs，方式 2。倒地和踉跄用 Mixamo 动作，先告诉我要下载哪几个、文件名叫什么；文件没到之前先用关键帧做出来。

【网页里直接编辑（不想进 Blender 时）】
点画面里的人物 / 道具 / 场景物件拖动（W 移动、E 旋转、R 缩放）；「自动关键帧」开关自己选，关着时按 K 才记；
时间线每个对象一条关键帧轨道，可拖、删、复制粘贴；Ctrl+Z 撤销，Ctrl+S 直接保存到工程的 scene.json，没保存刷新也能恢复草稿。
自由观察：左键环绕、右键平移、滚轮推拉、按住右键 + WASD 飞行、F 聚焦；T 俯视平面图；右下角小窗看镜头画面；
相机路径上的点可拖；运镜微调（推拉升降摇移）、FOV 滑杆、「设为镜头机位」；镜头可切分 / 删除 / 改名 / 拖切点。
天气：晴 / 阴 / 小雨 / 大雨 / 雷雨 / 雪 / 大雾预设和滑杆、时间段、闪电，都记在播放头处，可上时间线。
姿态：选中角色后换姿态、14 个关节滑杆微调（也能修正动捕）、手部接触选目标或拖小球。

【画幅】
工程画幅在顶栏随时切换（可撤销）；镜头页可给单个镜头设画幅（自动加黑边）、显示其他画幅的取景参考线；
导出 MP4 / Blender 时可另选画幅和清晰度，例如工程做 16:9、导出 21:9：选「裁切」= 上下裁掉（和参考线一致），选「扩展」= 两边多看到场景。

【夜景、暗场】
夜景不要把参考视频导黑：网页会提示过暗的镜头；在「镜头」页点「参考提亮 · 自动」，导出 MP4 时「画面」选「提亮参考」（或「白膜平光」「深度图」）。
故事光照照常保留（导出 Blender 也不变）；夜晚、冷光等氛围写进生成提示词，并说明参考视频是提亮过的、只参考构图和动作。

【视频动捕（不用动捕设备）】
用手机拍一段真人做动作的视频（手机固定、全身入画、光线充足、尽量只有一个人），在网页里本机识别，视频不上传。
选中角色 →「角色 · 姿态」页 →「视频动捕」→ 选视频 →「识别动作」。识别完右边会把动作临时套到所选角色上：点「▶ 对比播放」或拖滑杆，和原视频逐帧对照，满意了再「加到角色」，不满意直接关掉。
「起点」设动作从第几秒开始（默认播放头，可一键 0 秒）；动作超出工程结尾的部分会提前提示。
「原有动作」：叠加（保留原动作）/ 覆盖姿态（替换这段时间的原动作，站位朝向照旧）/ 完全覆盖（原地做动作，结束后走回原路线）。原关键帧不删，Ctrl+Z 可撤销。
「精细识别」（默认关）：摔倒、打斗、地板动作等复杂动作时勾上，最难的几帧少认错，识别慢 2–4 倍。
人偶自动踩地，不会穿地或悬空；视频里双脚离地的跳跃会真的跳起来（要求手机固定、双脚完整入画）。
请用 Chrome 或 Edge 打开预演页做视频动捕（Safari 里识别模型会崩溃，其他功能 Safari 都正常）。

【局部修改】
继续修改已有工程。5–10秒镜头里，B的肩挡住了A。相机沿画面右侧平移一点，目标仍指向A与门之间；保持角色路径和道具归属。
保存为v02，检查修改镜头起中末和相邻切点，说明具体改了哪些参数。

【导出参考视频】
预演已满意。用「导出 MP4」逐帧导出参考视频，确认时长、帧数、尺寸和画面不是黑帧。

【导出 Blender 工程】
预演满意后点「导出 Blender」，得到带完整动画的 <标题>_blender.glb。
在 Blender（3.6 以上，Intel Mac 用 4.5 LTS）的「脚本」工作区打开工程里的 blender_setup.py 点运行，
或命令行：blender -b -P blender_setup.py -- <标题>_blender.glb
会生成同名 .blend：帧率、分辨率、每镜一台相机并按镜头标记自动切镜、灯光、世界光都已设好。

【生成交接】
准备生成参考包，按完整事件评估约15秒的小段，标清从原预演取哪段、局部时码及跨段状态。
视频约束机位、构图、走位和事件顺序；图片约束身份、服装、专属道具和场景；最终表演不继承代理角色的僵硬动作、滑步与关节抽动。
未给实际上传标签的保留具名待绑定；只整理资料，暂不上传或代生成。

# 影棚开拍前的忙碌日常：完整生成提示词示例

这是随包示例预演（30 秒斯坦尼康一镜到底、14 个角色）的交接文本，演示一镜到底怎样按主体交接点分段，以及怎样写跨段状态。在 15 秒处切开，这一刻摄影机正好从女演员转向导演和摄影指导，两段之间用同一机位首尾相接。占位标签要在真实上传后替换。这份示例没有实际调用视频模型，也没有附带人物或场景图片。新项目的剧情不同，要改写事件，不能原样套用。

```text
【第1段｜取原预演 0.000–15.000 秒，以下时码从本段 0 秒开始】
【目标】生成 15.000 秒、16:9 横屏的写实电影感纪录片式影棚日常。斯坦尼康一镜到底，不切镜。28mm、f/2.8。不要生成文字标签、坐标网格或 UI。

【素材绑定】
{{本段预演视频}}：原预演 0–15 秒。

灯光师老郑 {{老郑人物图}}、灯光助理 {{灯光助理人物图}}，推着装在滚轮灯架上的大型 LED 柔光灯 {{柔光灯道具图}}。
女演员 {{女演员人物图}}、化妆师 {{化妆师人物图}}、服装助理 {{服装助理人物图}}（手里拿着一件外套）。
导演 {{导演人物图}}（戴棒球帽）、摄影指导 {{摄影指导人物图}}（脖子上挂着取景器），本段只在背景里站着聊天。
影棚与客厅布景 {{ENV01场景图}}。
道具归属：托盘上一共三杯咖啡，5.6 秒第一杯被老郑拿走；女演员肩上的披肩 14 秒左右被服装助理取下。

【参考使用范围】
参考视频控制摄影机路径、高度和朝向、主体交接的时机、人物站位和事件先后。
参考图控制人物身份、服装、道具和场景细节，不继承定妆图的棚拍背景和展示姿势。
预演里的白膜人偶、标签和简单道具只是定位代理。不迁移逐帧骨骼、僵硬手臂、机械步频和滑步，按真人重新形成熟练、轻松的工作表演；所有人不看镜头。
光：布景外是影棚顶部冷白色的工作灯，像车间；化妆镜周围一圈暖白灯泡。

【0.000–4.000秒｜后拉跟随，特写转中景】
开场是托盘上冒着热气的纸杯咖啡特写，托盘随脚步轻轻晃。摄影机后拉，露出端托盘的小周：她用肩膀顶开入口大门走进影棚，向画右快步走，侧身避开地上一卷线缆，顺手冲一个扛器材箱往外走的人点头。摄影机在她身前同速后退。

【4.000–9.000秒｜主体交接给灯光师】
老郑和助理推着柔光灯迎面过来，小周递给老郑一杯咖啡（5.6 秒）；老郑接过来抿一口，冲她抬抬下巴，小周继续往画右走出画。摄影机不再跟小周，贴着灯架绕到老郑身侧，跟着灯架的滚轮向布景方向移动，滚轮压过地上的胶带轻轻一颠。

【9.000–11.000秒｜随灯升起上摇】
老郑踩住滚轮刹车，转动摇柄，柔光灯面板一节一节升高并亮起；摄影机跟着灯面上摇仰拍，越过灯面露出影棚高处的金属灯光走道，再顺势下摇，落向化妆区。

【11.000–15.000秒｜半环绕女演员】
摄影机从化妆镜那圈灯泡的前景里穿过，以女演员为中心，从她的画左后方缓慢半环绕到正面。她闭着眼坐在高脚椅上，嘴唇轻动默念台词；化妆师用粉扑轻按她的额头和鼻梁，再用小刷子扫过眉尾；服装助理走近，取下她肩上的披肩，替她理好衬衫领子。

【第1段结束状态】摄影机在女演员正面，胸部高度；导演和摄影指导正从她身后走进画面；老郑的柔光灯已经升起、亮着；小周在画右的监视器区。

【第2段｜取原预演 15.000–30.000 秒，以下时码从本段 0 秒开始】
【目标】接第1段最后一帧的同一机位，继续斯坦尼康一镜到底 15.000 秒，从女演员身边走到灯光走道上俯拍全景。
本段新增：副导演 {{副导演人物图}}（手持对讲机）、录音师 {{录音师人物图}}（挑杆话筒）、两名置景工人、摄影机组。
光：越往右越暖。客厅布景里是暖黄色的戏用灯，从布景墙上方斜照进来；监视器屏幕泛冷蓝光；布景里有一层极淡的烟雾。

【0.000–4.000秒｜主体交接给导演和摄影指导，引导后退】
摄影机转向导演和摄影指导，在两人身前后退引导，两人并肩走向画右的监视器区。导演一边走一边用双手比出画框：「这场光再暖一点。」摄影指导低头看一眼取景器，点两下头：「好，我让老郑调。」小周从画右迎面走来，往两人手里各塞一杯咖啡，三人错身而过。女演员这时起身走向布景。

【4.000–6.000秒｜穿越前景】
两人从摄影机两侧走过，在监视器前停下弯腰看屏幕。摄影机原地转身，从两人肩膀之间、再从两台监视器之间的窄缝穿过去，监视器边框从画面两侧掠过；正前方是客厅布景的开口，暖光从里面漫出来。副导演快步走到开口一侧，举起对讲机：「各部门准备！」

【6.000–9.000秒｜推进，穿入布景】
摄影机推向布景开口，录音师正把挑杆话筒举高，摄影机低头从挑杆下面穿进暖色的客厅布景。两名置景工人把沙发往画左挪一点，一人蹲下用卷尺量茶几到沙发的距离，另一人比个「好」的手势，两人弯腰快步退出布景。

【9.000–12.000秒｜穿出布景，登梯升高】
摄影机穿过后墙的布景门，来到布景墙背面：木架子、沙袋、贴着胶带的背板。摄影机沿金属楼梯向上，栏杆一根根从前景掠过，画面逐渐升高。

【12.000–15.000秒｜灯光走道俯拍】
摄影机停在约 5 米高的灯光走道上，越过金属栏杆俯拍整个片场：女演员已经站到布景里的沙发旁，化妆师和服装助理退到布景外，录音师把挑杆伸到她头顶，摄影机组推着摄影机就位，小周端着空托盘站在墙边。副导演举起一只手（13.2 秒），布景里的戏用灯同时亮起，客厅被暖黄色的光填满；所有人安静下来，女演员轻轻吸一口气、肩膀放松，烟雾在光里缓缓流动。画面停在这一刻。

【声音】脚步、对讲机电流声、灯架滑轮、轻声交谈，无背景音乐；只有导演、摄影指导、副导演各一句台词。
【复查】全程一镜到底不切镜；三杯咖啡分别只给老郑、导演、摄影指导；两段接缝处机位、人物站位和光线一致；结尾布景灯只亮一次；没有人看镜头；没有灰色代理材质、UI、标签或无关棚拍背景。
```

示例的几何代理足以检查主体交接、走位、接触和摄影机路径。最终的面孔、材质、步态和光影取决于所用模型与输入素材，不能把写好提示词当作结果已经验收。

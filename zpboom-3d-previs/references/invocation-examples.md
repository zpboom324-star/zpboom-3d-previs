# 可直接使用的调用示例

需要完整生成文本时，读取 [影棚开拍前的忙碌日常完整示例](complete-example.md)，它对应随包 30 秒一镜到底示例预演的主体交接、道具传递和两段跨段状态。

## 首次制作

```text
使用 zpboom-3d-previs（ZPboom.AI · 3D预演导演）。
我需要制作30秒、16:9的影棚一镜到底短片。附件有分镜脚本、人物和场景参考。
先把分镜整理成机位、目标点、角色路径和道具归属，再做可在浏览器运行的3D预演。
页面要能暂停调机位、拖时间轴、保存配置、打开干净画面录制。
用简单3D代理走通空间，暂不调用付费视频生成。工程输出到我指定的项目目录。
```

示例分镜（随包示范案例就是这一条）：0–4秒场务端着咖啡推门进棚，摄影机在她身前后退；4–9秒她把咖啡递给推灯的灯光师，主体交接给灯架；9–11秒随灯面升起上摇；11–15秒半环绕补妆的女演员；15–19秒在导演和摄影指导身前后退引导；19–24秒从两台监视器之间穿过、从挑杆下钻进布景；24–30秒走上金属楼梯，在灯光走道上俯拍，副导演举手、布景灯全亮。
推门、灯面升降要用 `set` 节点 / 道具关键帧加 `rigs` 做出来，布景灯全亮用 `glow` 特效的 `lightIntensity`，不能只把分镜文字写进 action。

## 开工确认（一次说清，跳过提问）

新建工程前会先问 4 题：人物白膜、预演画面亮度、机位和空间冲突时怎么办、这次做到哪一步。想一次说清、直接开工，可以这样写：

```text
使用 zpboom-3d-previs。简化胶囊白膜；画面保持明亮可读；机位装不下时保持空间真实、偏离处标注；
这次做到预演 + 导出参考视频。下面是分镜……
```

没写到的题，开工前会用一次提问补齐；回答记在工程的 revision-log.md「开工确认」里，之后修改都按它来。

## 指定动作方式

不写就默认方式 1（关键帧直接做）；要动捕时写明方式 2。

```text
使用 zpboom-3d-previs，方式 1（关键帧直接做）。12秒、16:9，两人对峙后一人转身离开。
只要粗预演看机位和节奏，不用动捕。
```

```text
使用 zpboom-3d-previs，方式 2（关键帧 + 动捕）。7秒、16:9，乘客心脏病发作倒地。
倒地和踉跄用 Mixamo 动作，先告诉我要下载哪几个、文件名叫什么；文件没到之前先用关键帧做出来。
```

## 修改已有工程

```text
继续修改我上传的HTML/scene.json。5–10秒的镜头，B的肩挡住了A。
让相机沿画面右侧平移一点，目标点仍指向A与门之间，保持人物和道具路径不变。
保存为v02，检查切点前后；告诉我具体改了哪个镜头和参数。
```

```text
把全片改成9:16，先重新构图让A/B/C关键动作完整入画，不能只把原画面裁窄。
不要改剧情时长。导出新配置，并用竖屏干净模式检查每镜。
```

## 准备生成

```text
预演已经满意，参考视频和人物/道具/场景图已准备好。
整理素材绑定表和生成提示词。多人项目先按完整事件规划约15秒的小段，标清实际裁切时间和跨段状态。
参考视频约束运镜、走位和事件顺序，不继承代理人物的僵硬动作；图片约束外观与道具归属。
上传标签我没有提供的先标待绑定，不编造编号。先交参考包，不提交付费任务。
```

## 普通聊天辅助模式

没有本地文件执行和技能安装能力的聊天产品，可以复制本段配合粘贴分镜：

```text
请作为3D预演导演，帮我把下面的分镜拆成可执行的网页3D制作说明。
每镜列出时间、事件、角色身份与专属道具、相机起止位置与目标点、角色路径、前后状态和验收点。
请提供完整HTML/JavaScript工程代码或明确的文件内容，使用Three.js，运动按时间采样，支持暂停、拖动进度、切镜、调机位和保存配置。
如果你不能在本机运行代码或看浏览器，明确说明已完成与待验证部分，不要声称安装了技能、录制了视频或生成了成片。
最后给出素材绑定表和生成提示词，区分“预演控制摄影与空间”和“图片控制设计”，最终表演不继承代理动作。
我的分镜如下：
```

该模式是指令辅助，用户仍需自行保存代码、启动运行和录制。把文本发给聊天模型不等于已安装本技能，也不能保证目标产品支持生成或执行完整工程。

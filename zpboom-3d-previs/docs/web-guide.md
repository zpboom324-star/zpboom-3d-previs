## 1. 打开工程

预演网页必须通过**本地 HTTP 服务**打开，不能双击 `index.html`。

```bash
python3 -m http.server 8000 --bind 127.0.0.1 --directory "工程文件夹路径"
```

然后在浏览器打开 `http://127.0.0.1:8000`。

- **推荐 Chrome 或 Edge**：保存能直接写回工程文件、能逐帧导出 MP4、能做视频动捕。
- Safari 能打开和编辑，但视频动捕会崩溃，保存会改为下载文件。
- 端口 8000 被占用就换成 8001、8002……
- 左下角状态栏显示「预演已就绪」就是加载成功了。如果显示错误信息，按提示处理，或者把这句话发给 AI 助手。

## 3. 顶栏

| 按钮 | 作用 |
| --- | --- |
| 工程标题 | 显示工程名 |
| 画幅下拉（16:9 等） | 切换整个工程的画幅：16:9 / 21:9 宽银幕 / 9:16 竖屏 / 1:1 / 4:3 / 3:4。每个镜头的竖直视角不变，画面变宽或变窄。可撤销 |
| 人物白膜下拉 | 精细白膜 / 简化胶囊。只换人物外形，不改动作；简化胶囊不显示道具。可撤销 |
| 撤销 / 重做 | Ctrl+Z / Ctrl+Shift+Z，最多 100 步 |
| 保存 | 写回工程的 `scene.json`（Ctrl+S） |
| 导入 | 打开另一份 `scene.json` 替换当前内容 |
| 导出配置 | 把当前内容下载成一份 `scene.json`（备份、发给别人） |
| 干净画面 | 隐藏所有界面，只留画面，适合录屏或给人看；Esc 返回 |
| 导出 Blender | 导出带完整动画的 GLB，再用工程里的 `blender_setup.py` 生成 .blend |
| 导出 MP4 | 逐帧导出参考视频（橙色主按钮） |

## 5. 时间线

时间线从上到下：

- **镜头轨道**：每个镜头一块，显示镜头名和起止时间。**单击**镜头块跳到这一镜开头；**按住拖动**是拖播放头；**拖动镜头之间的竖条**改切点，两边镜头原来的运动不变。
- **声音轨道**：声音提示的位置（例如「声：脚步」「台词」）。播放到时会在画面底部显示 1 秒多（干净画面和导出时不显示）。
- **天气轨道**：天气关键帧；黄色竖线是闪电。
- **对象轨道**：每个人物、道具、结构动画各一条，相机也有一条。菱形是关键帧。

关键帧的操作：

| 操作 | 方法 |
| --- | --- |
| 选中并跳过去 | 单击关键帧 |
| 改时间 | 左右拖动（吸附到整帧，不能越过相邻关键帧） |
| 删除 | 选中后按 Delete，或点「选中」卡片里的「删除这个关键帧」 |
| 复制到播放头 | Ctrl+C，移动播放头，Ctrl+V |
| 改缓动 | 「选中」卡片里的「缓动」：平滑 / 匀速 / 停住 |

**第一个关键帧固定在 0 秒**；人物、结构动画、相机这类需要覆盖全片的轨道，最后一个关键帧固定在结尾。

## 6. 在画面里选中和拖动

1. **点画面里的人物、道具或场景物件**就选中了，检查器的「选中」卡片会显示它的名字和数值。
2. 画面左侧的工具条切换手柄：
   - **移动（W）**：拖箭头沿一个方向移动，拖平面方块在平面上移动；
   - **旋转（E）**：人物只能绕竖直轴转（改朝向）；
   - **缩放（R）**：只对场景物件有效。
3. **取消选择**：点工具条上的 ×，或按 Esc。

拖动的结果记到哪里：

| 对象 | 记成 |
| --- | --- |
| 人物 | 播放头处的角色关键帧（只改位置和朝向，姿态、手部接触等保留） |
| 放在场景里的道具 | 播放头处的道具关键帧 |
| 拿在手里的道具 | 握持偏移（静态，全片生效） |
| 场景物件（墙、桌子……） | 物件本身的位置 / 角度 / 大小（静态；重复排列的会一起移动） |

**精确输入**：「选中」卡片里直接改位置 X / Y / Z 和角度，点「应用数值」。坐标单位是米，Y 向上。

## 7. 关键帧：自动记、手动记、改、删

播放条上的「**自动关键帧**」开关（N 切换，状态记在浏览器里）：

- **开**：拖完对象，立刻在播放头处记一个关键帧。
- **关**：拖完之后「记关键帧」按钮会闪，按 **K** 才记；如果没按 K 就去拖时间轴，这次拖动会被放弃。适合先试试位置再决定。

**K 的另一个用法**：没选中任何对象时按 K，会把当前画面记成当前镜头在播放头处的**相机关键帧**。

小技巧：

- 想让人物「在这一段停住不动」，在停留段的开头关键帧把缓动设成「停住」。
- 想让运动匀速（例如推轨、机械运动），设成「匀速」。
- 两个关键帧间隔不到一帧，会被当成瞬移（硬切），不做平滑。

## 8. 检查器 ①：角色 · 姿态

### 选角色

这一页顶部有一排角色小标签，点一下选中这个角色（和在画面里点人物一样）。

### 角色关键帧（数值）

展开后可以直接输入位置和**朝向 yaw**（弧度，0 = 面向 -Z，-1.57 = 面向画右 +X，1.57 = 面向画左 -X），点「写入角色关键帧」。

### 姿态

| 控件 | 作用 |
| --- | --- |
| 姿态库 | 在播放头处把这个角色换成某个姿态（站、跑、蹲、出拳、倒地……），前后关键帧之间会自动过渡 |
| 关节微调滑杆（14 个） | 前倾、低头抬头、转头、左右臂前后 / 外展、左右肘、左右腿前后、左右膝、整体下沉。单位显示为度，叠加在姿态库之上，**也能叠加在动捕动作上修正动作** |
| 清除这一帧的微调 | 把播放头处的关节微调清零 |
| 视频动捕：用手机视频生成动作… | 打开视频动捕窗口（见第 13 节） |
| 实时动捕：用摄像头跟着时间线表演… | 打开视频动捕窗口并直接打开电脑摄像头（见第 13 节「实时动捕」） |

### 手部接触（左手 / 右手）

让手准确地抓住、搭住某个东西（握枪、拍肩、扣手腕、扶沙发……）：

1. 在下拉里选目标：「不接触」、「固定位置（拖小球）」，或者某个部位 / 道具点（例如 `B.hand_R` 是角色 B 的右手、`B.shoulder_L` 是左肩、`CUP1.tip` 是道具上的点）。
2. 拖「接触力度」：0 = 不接触，1 = 完全贴上；中间值是半贴合，用来做「手慢慢伸过去」。
3. 选「固定位置（拖小球）」时，点「拖」会在画面里出现一个小球，拖到想放手的位置。

接触按关键帧过渡：在前一个关键帧力度 0、后一个关键帧力度 1，手就会伸过去。

## 9. 检查器 ②：镜头

上半部分常驻的「**当前镜头**」卡片：

- 镜头名称：点击直接改，回车确认。
- 「在播放头切分」：把当前镜头切成两个，运动保持不变。
- 「删除此镜」：删除当前镜头，时间并入相邻镜头，被延长的镜头原有运动不变。

「镜头」标签页：

| 控件 | 作用 |
| --- | --- |
| 视角 FOV | 拖动立即生效，旁边显示等效焦距（16:9 下 28mm ≈ 46°，35mm ≈ 38°，50mm ≈ 27°，85mm ≈ 16°） |
| 此镜画幅 | 这一镜单独的画幅；比工程宽就上下加黑边，比工程窄就左右加黑边，导出也带上 |
| 取景参考线 | 在画面上叠一个其他画幅的取景框（只是参考，不改工程），方便「做 16:9、导出 21:9」 |
| 参考提亮 | 暗场镜头的提亮滑杆；「自动」会找到让每个镜头都看得清的最小值。只影响参考画面，故事光照不变 |
| 运镜微调 | 先选步长（细 5 cm / 0.5°、中 20 cm / 2°、粗 60 cm / 6°），再点 推 / 拉 / 升 / 降 / 左移 / 右移 / 左摇 / 右摇 / 上仰 / 下俯 |
| 写入相机关键帧 | 把微调后的机位写进当前镜头 |
| 设为镜头机位 | 把自由观察里找好的画面记成当前镜头在播放头处的相机关键帧（K） |

运镜微调：开着自动关键帧、并且在镜头画面里时，点按钮直接写入；否则会先切到自由观察预览，满意后点「设为镜头机位」。

## 10. 检查器 ③：天气

| 控件 | 作用 |
| --- | --- |
| 预设 | 晴 / 阴 / 小雨 / 大雨 / 雷雨 / 雪 / 大雾，一键套用 |
| 雨、雪 | 雨丝和地面溅水 / 雪花的密度。屋顶、桌面等遮挡物下面不下 |
| 雾 | 在原有雾的基础上加浓 |
| 风力、风向 | 雨的斜度、雪的飘移方向 |
| 阴天 | 压暗平行光、背景变灰 |
| 地面湿 | 地面变暗、变光滑反光 |
| 时间段 | 关闭（原始光线）/ 黎明 / 上午 / 正午 / 下午 / 黄昏 / 傍晚 / 夜晚，改变日光的强度和颜色；手电、灯泡等不受影响 |
| ⚡ 在播放头加闪电 | 画面闪白两下 + 一盏闪光灯，可以对准雷声提示 |
| 清除全部天气 | |

所有天气设置都**记在播放头处**，前后之间平滑过渡。例如 0 秒晴、5 秒大雨，就是 5 秒里慢慢下起来。

## 11. 检查器 ④：说明

- **关键帧与说明**（只读）：当前对象的关键帧摘要和操作提示。
- **恢复项目配置**：放弃所有没保存的修改，回到最近一次载入的 `scene.json`。
- **快捷键速查**。

> 道具换手、结构动画（开门、升降）、特效（开灯、火花）目前没有专门的网页面板。要改这些，直接告诉 AI 助手（例如「门在 3 秒开始开，4 秒开到 90 度」），或者改 `scene.json`。

## 12. 自由观察、俯视和相机路径

播放条右侧的开关：

| 开关 | 作用 |
| --- | --- |
| 自由观察 | 脱离分镜相机，随便看场景：左键拖动环绕，右键或 Shift+左键平移，滚轮推拉；按住右键再按 W/A/S/D 前后左右飞、Q/E 下降上升（按住 Shift 加速）；F 聚焦选中的对象 |
| 俯视（T） | 正上方的平面图：拖空白处平移、滚轮缩放；自动剖掉 2.2 米以上的屋顶天花板。适合摆走位 |
| 小窗 | 自由观察 / 俯视时，右下角小窗显示分镜相机的实际画面 |
| 路径 | 显示当前镜头的相机路径（橙）、看向路径（蓝）和取景框。路径上的圆点是相机关键帧，**点中后可以拖动**，也可以在「选中」卡片里输入坐标 |
| 辅助显示 | 网格、角色标签和编辑用工作光（干净画面和导出时自动关闭） |

自由观察里拖时间轴、播放，视角不会跳回分镜相机。找好角度后按 K（或「设为镜头机位」）就能变成真正的镜头。

## 13. 视频动捕

用手机拍一段真人做动作的视频，在网页里识别成动作，加到某个角色身上。**全部在本机处理，视频不上传。请用 Chrome 或 Edge。**

### 拍视频的要求

- 手机固定不动（三脚架或靠在东西上）；
- 全身入画，包括双脚；
- 光线充足、背景简单，画面里尽量只有一个人。

### 操作步骤

1. 在「角色 · 姿态」页点「**视频动捕：用手机视频生成动作…**」。
2. 「**选择视频…**」选好文件。
3. 设置识别选项：
   - **截取**：只识别视频的某一段（开始秒 / 结束秒）；
   - **平滑**：越大越稳、越小越跟手；
   - **朝向对准正面**：把第一帧的身体朝向转成正对前方，之后的转身保留；
   - **精细识别**：摔倒、打斗、地板动作、四肢互相遮挡时勾上，最难的几帧少认错，但识别慢 2–4 倍。普通动作不用开；改了要重新识别。
4. 点「**识别动作**」，等进度走完。
5. 识别完会把动作**临时**套到所选角色上。点「**▶ 对比播放**」（或按空格）让原视频和白膜同步播放，或拖滑杆逐帧对照。
6. 设置怎么加进工程：
   - **动作名称**；
   - **加到角色**：选哪个角色；
   - **起点**：动作从工程第几秒开始播放，可以一键设成「0 秒」或「播放头」。动作超出工程结尾的部分会提前提示；
   - **原有动作**：
     - 叠加（保留原动作）；
     - 覆盖姿态（替换这段时间的动作，站位和朝向照旧）；
     - 完全覆盖（原地做动作，结束后按正常步速走回原来的路线）。
7. 满意点「**加到角色**」；不满意直接「关闭」，工程不会变。

加进去以后原来的关键帧不会删，Ctrl+Z 可以撤销。人偶会自动踩地，不会穿地或悬空；视频里双脚离地的跳跃会真的跳起来。动作有小问题时，用姿态卡片的关节滑杆在那几帧上微调。

### 实时动捕（电脑摄像头）

不用先拍视频：对着电脑摄像头做动作，人偶实时跟着动；也可以跟着时间线录一段，直接加到角色上。**摄像头画面只在本页识别，不上传、不保存。**

要求：用 Chrome 或 Edge，并且通过 `http://127.0.0.1` 或 `localhost` 打开工程（浏览器只在这类地址上允许用摄像头）；全身入画（笔记本摄像头一般要退到 2.5–3 米）、光线充足；**录制时浏览器窗口保持在前台**。

1. 在「角色 · 姿态」页点「**实时动捕：用摄像头跟着时间线表演…**」（已经打开视频动捕窗口时，点顶部的「**📷 摄像头实时**」）。浏览器第一次会问是否允许使用摄像头，点「**允许**」。
2. 先选好「**加到角色**」「**起点**」和「**原有动作**」（同上）。
3. 电脑接了不止一个摄像头（比如外接摄像头、当摄像头用的手机）时，顶部会出现**摄像头下拉框**，选哪个就立即换成哪个；下次打开会自动用上次选的那个，它没连上时用默认摄像头。录制中不能切换。
4. 右上角的画面切换：
   - **左：镜头画面**：左边大画面是分镜相机在当前时间的画面，所选角色跟着你动，其他角色、机位照常；右边小画面是摄像头 + 骨架。适合看着镜头表演。
   - **左：摄像头 + 骨架**：左边是摄像头和识别出的骨架，右边是套到所选角色上的白膜预览。适合检查识别准不准。
   - 旁边显示实时识别的帧率。左上角提示「认出人了」或「没认出人：请让全身完整入画」。
5. 点「**● 录制**」：3 秒倒计时后，工程从「起点」开始按真实时间播放，跟着画面表演。再点「**■ 停止**」结束；播到工程结尾会自动停。倒计时期间再点一次是取消。
6. 停止后自动进入回放：「▶ 对比播放」或拖滑杆检查（摄像头画面不保存，所以左边只显示骨架）。满意点「**加到角色**」，不满意点「**● 重新录制**」。认出人的帧太少（不到一半）时不能加，按提示退远一点、把灯打亮再录。
7. 关掉窗口，摄像头随即关闭；按空格播放就能看到角色在做录下来的动作，Ctrl+Z 撤销。

录下来的动作和视频动捕完全一样处理：平滑、朝向对准正面、自动踩地、跳起检测、覆盖方式都照常生效。实测 Windows 台式机（RTX 显卡）Chrome / Edge 识别用显卡，跟满摄像头的 30 帧/秒。

**用手机当摄像头**：电脑没有摄像头，或者想把机位放到 3 米外拍全身，可以让 Windows 把手机当成摄像头，网页里就能直接用（在摄像头下拉框里选它）。
- 安卓 + Windows 11：「设置 → 蓝牙和其他设备 → 移动设备」里允许连接手机，手机装「连接至 Windows」，打开「用作已连接的摄像头」。
- 安卓或 iPhone：用 Camo、DroidCam、Iriun Webcam 等软件，手机和电脑各装一个。用 USB 数据线连接延迟最低；Wi-Fi 也能用，会慢一点。
- 不要在手机浏览器里直接打开预演页面：用局域网地址（`http://192.168.x.x`）打开时浏览器不允许用摄像头，手机识别也慢。让电脑跑页面，手机只负责拍。
- 手机断开连接时会提示「摄像头断开了」，正在录的部分会保留。

## 14. 保存、草稿、导入导出配置

- **保存（Ctrl+S）**：Chrome / Edge 第一次会让你在文件选择框里**选中工程文件夹里的 `scene.json`**，之后每次直接覆盖它；其他浏览器改为下载一份 `scene.json`，需要你自己放回工程文件夹。
- **自动草稿**：每次改动都会存一份草稿在浏览器里。没保存就刷新或关闭，下次打开时检查器里会出现提示条「发现未保存的草稿」：「恢复」把草稿找回来，「丢弃」删掉草稿。
- **导出配置**：下载当前内容的 `scene.json`，适合留版本备份（例如另存为 `scene_v02.json`）。
- **导入**：打开一份 `scene.json`，直接替换当前内容。**导入不能撤销**，导入前先「导出配置」备份一份。

> 如果工程里有 AI 助手写的 `tools/` 生成脚本，你在网页里保存之后，**不要再运行这个脚本**，否则会覆盖你的修改。让助手继续改时，告诉它你在网页里改过。

## 15. 导出 MP4

点顶栏「**导出 MP4**」，弹出导出设置：

| 设置 | 选项 |
| --- | --- |
| 画幅 | 默认跟工程一致，也可以另选 |
| 画幅不同时 | 裁切（和取景参考线一致）/ 扩展（两边多看到场景） |
| 画面 | 原样光照 / 提亮参考（推荐给视频模型）/ 白膜平光（无阴影、去雾和雨雪，只看形体动作）/ 深度图（近白远黑） |
| 一键提亮 | 有镜头太暗时会出现，点一下自动提亮 |
| 清晰度 | 720p / 1080p / 4K（2160p） |

点「**开始导出**」。导出过程中：

- 按钮变成「取消导出」，状态栏显示「正在逐帧导出 MP4：第几帧 / 总帧数」；
- 每一帧单独渲染，**不会掉帧**，时长和帧数与工程完全一致；
- 网格、标签、工作光自动隐藏；
- 页面放在后台时导出会变慢，但不影响结果。

导出完成后浏览器会下载 MP4。16:9 默认是 1920×1080，21:9 是 2520×1080，9:16 是 1080×1920。

浏览器不支持逐帧编码（WebCodecs）时，会退回实时录制 WebM，这种方式可能掉帧，建议换 Chrome / Edge。

## 16. 导出 Blender

1. 点顶栏「**导出 Blender**」，在设置里选画幅和清晰度（决定 Blender 里的相机和分辨率），开始导出。
2. 浏览器下载 `<标题>_blender.glb`，里面是人物关节、道具、结构动画、每个镜头一台相机、灯光的逐帧动画。
3. 打开 Blender（3.6 以上；Intel Mac 建议 4.5 LTS）→ 切到「Scripting / 脚本」工作区 → 在文本编辑器里打开工程文件夹里的 `blender_setup.py` → 点运行 ▶。
4. 脚本会自动找到最新的 GLB，导入并在旁边保存同名 `.blend`；帧率、分辨率、按镜头标记自动切相机、灯光、世界光都已设好。已存在同名文件时另存为 `_v2`，不会覆盖你改过的工程。

## 17. 常用操作流程

### 让一个人在某一秒走到某个位置

1. 拖播放头到那一秒。
2. 打开「自动关键帧」。
3. 点人物，按 W 拖到目标位置（俯视 T 下更好摆）。
4. 播放检查走过去的路线；需要停一会儿，就在到达的那一帧再记一个相同位置的关键帧。

### 调整一个镜头的机位

1. 跳到这一镜（单击时间线上的镜头块）。
2. 方法 A：「镜头」页用运镜微调一下一下推拉摇移，点「写入相机关键帧」。
3. 方法 B：打开「自由观察」找好角度，打开「小窗」对照，按 K「设为镜头机位」。
4. 方法 C：打开「路径」，在自由观察或俯视里直接拖相机路径上的圆点。
5. 逐帧检查这一镜的起点、终点和切点前后。

### 给人物换一个动作

1. 播放头放到动作开始的地方，选中角色。
2. 「姿态库」选一个姿态（例如「出拳」）。
3. 在动作结束的地方再选回原来的姿态。
4. 细节不对，用关节滑杆微调。

### 让手抓住东西

1. 在手伸过去之前的一帧：手部接触选目标，力度 0。
2. 在手抓住的那一帧：同一个目标，力度 1。
3. 松手的那一帧：力度回到 0。

### 夜景导出给视频模型

1. 「镜头」页 → 参考提亮 →「自动」。
2. 导出 MP4 →「画面」选「提亮参考」。
3. 在生成提示词里写清楚「最终是夜景，参考视频是提亮过的，只参考构图和动作」。

### 同一个工程出竖屏版

1. 顶栏画幅切到 9:16（或者导出时另选 9:16）。
2. 逐镜检查关键动作是否完整入画，不够就调机位，不要只把画面裁窄。
3. 用「导出配置」另存一份，避免和横屏版混在一起。

## 19. 遇到问题

| 现象 | 处理 |
| --- | --- |
| 双击 index.html 一片空白 | 必须用本地 HTTP 服务打开（第 1 节） |
| 状态栏显示「预演未能启动」+ 错误信息 | `scene.json` 里有写错的地方。把错误信息发给 AI 助手，或用「导入」换回之前导出的备份 |
| 升级后新按钮点了没反应 | 浏览器在用旧缓存，按 Cmd+Shift+R（Windows：Ctrl+Shift+R）强制刷新 |
| 保存时提示选择文件 | Chrome / Edge 第一次保存需要选中工程里的 `scene.json`，之后就不会再问 |
| 刷新后修改不见了 | 看检查器里有没有「发现未保存的草稿」提示条；有就点「恢复」，然后 Ctrl+S |
| 拖了人物但没变化 | 自动关键帧关着时，拖完要按 K 才记；拖时间轴前没按 K 会放弃这次拖动 |
| 画面太暗看不清 | 「镜头」页 → 参考提亮 →「自动」 |
| 视频动捕报错 | 换 Chrome 或 Edge；确认视频里全身入画、光线够 |
| 实时动捕打不开摄像头 | 提示没有权限：点地址栏左边的摄像头图标改成「允许」，再点「📷 摄像头实时」。提示没找到摄像头：检查摄像头（或当摄像头用的手机）是否连好。提示被占用：关掉会议软件、手机摄像头软件里的预览。一直停在「正在打开摄像头」：把浏览器窗口切到前台。用的不是想要的摄像头：在顶部的摄像头下拉框里换 |
| 导出 MP4 特别慢 | 把预演页面放在前台；4K 比 1080p 慢很多 |
| 人物穿进墙里 / 手没抓到 | 自由观察或俯视里检查位置；手部接触的力度是否为 1、目标是否选对 |
